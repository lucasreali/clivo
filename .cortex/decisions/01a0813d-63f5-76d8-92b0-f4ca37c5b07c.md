Every primitive in src/shared/ui that carries behavior now delegates to Base UI 1.8 (@base-ui/react, headless and unstyled): Modal to Dialog, the new Drawer to Drawer, Menu to Menu, Select to Select, Combobox to Combobox, Field/TextInput/Checkbox to Field, Input and Checkbox, Button to Button, and the Toaster in pending.tsx to Toast (which replaced the sonner dependency, now removed).

The hand-written versions were missing what is expensive to get right: the modal had no focus trap, no focus restore, no scroll lock and no portal; Menu was a details element with no roving focus, no arrow keys and no outside-press dismissal; Select and Combobox lacked typeahead, Home/End, scroll-into-view and any collision-aware positioning. All popups now render in a portal with Floating UI positioning, which removes the class of bug behind the panel-clipping fix (01a07e09).

The public prop signatures of shared/ui were kept, so no feature screen changed shape. The only call-site change was Checkbox moving from onChange(event) to onCheckedChange(checked) in ParameterControl, UserAccess, NewCustomer, SheetFieldControl and shared/form/fields.tsx. shared/ui is the adaptation layer: features import from #/shared/ui and never from @base-ui/react.

options.tsx no longer exports the OptionList/OptionItem/OptionNotice components (Select and Combobox have their own Item parts); it keeps the Option type plus the OPTION_POPUP/OPTION_ITEM/OPTION_NOTICE class constants, so both lists still look the same. The shared-option-list intent of 01a07de2 survives and Select stays a custom listbox rather than a native select element.

Rejected: Base Web (Uber's "baseui"), which ships Styletron CSS-in-JS and its own visual language and would fight the Tailwind v4 tokens. Deliberately left alone: purely visual primitives (Panel, Badge, Callout, EmptyState, Avatar), because adopting a Base UI part that adds no behavior is ceremony, and the 51 native title tooltips, which would be a UX change rather than a swap.

Verified with tsc, biome and a production build, plus a throwaway route driven in a real browser: focus trap and scroll lock on the modal, a Select opening above it, portal-positioned menu, checkbox toggling with aria-labelledby wiring, label/control association on Field, toast in the bottom-right corner and the drawer sliding in from the right.
