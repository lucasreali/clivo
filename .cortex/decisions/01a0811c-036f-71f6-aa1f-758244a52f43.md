All icons in CLIVO now come from `@phosphor-icons/react` (v2.1.10). Before this, every icon was a hand-written inline `<svg>` on a 16x16 grid with stroke-only paths, and the two navigation models (`navigation.ts`, `console-navigation.ts`) carried the icon as a raw SVG `path` string.

What changed:
- `NavigationItem.icon` and `ConsoleNavigationItem.icon` are now typed `Icon` (Phosphor's `ForwardRefExoticComponent<IconProps>`) and hold the icon *component*, not a path string. This trades a stringly-typed field for a type-checked reference and removes the name-to-glyph indirection a lookup map would need.
- Every inline `<svg>` was replaced: Sidebar/ConsoleRail entry icons, the Select chevron (`CaretDown`), the pending-feature toast (`WarningCircle`), the top-bar search and bell (`MagnifyingGlass`, `Bell`), the customer search box (`MagnifyingGlass`), the week-agenda pager (`CaretLeft`/`CaretRight`), and the `×` text glyphs in `Modal` and the customer search clear button (`X`).
- Colors are no longer hardcoded hex (`#1D9E75`, `#8B8A83`, `#5F5E5A`). Icons inherit `currentColor` and get their color from the semantic Tailwind tokens (`text-brand`, `text-faint`, `text-muted`, `text-warn`), so they follow the `@theme` palette in `src/styles.css`.
- Sizes are passed explicitly per call site to preserve the previous pixel dimensions (16 in the sidebar, 15 in the console rail and bell, 14 for search, 10 for the select chevron).
- Every icon is rendered with `aria-hidden="true"` — Phosphor's `IconBase` does not add it automatically; it only emits a `<title>` when an `alt` prop is given.

Rejected: keeping a `Record<string, Icon>` map in the components layer so the `model/` files would stay free of React types. It was rejected because the map key is a primitive that can fail at runtime and has to be kept in sync by hand, while the navigation models were already pure UI description (label + route + glyph), not domain logic.

Rejected: switching the active sidebar entry to `weight="fill"`. The previous design signalled active state through color alone and that was preserved.

Kept the default barrel import (`@phosphor-icons/react`) rather than the `/dist/ssr` entry: SSR is off in this app, and the production build tree-shakes it — no bundle grew disproportionately after the migration.

Verified with `pnpm check`, `npx tsc --noEmit` (the only errors are the pre-existing `CustomerHistoryView` typing errors in `use-open-encounter.ts` and `CustomerHistory.tsx`) and `pnpm build`.
