The native select renders its option popup through the OS, so the options could take neither cursor:pointer nor the design tokens — the affordance declared in src/styles.css reached the closed control only.

Select moved out of Field.tsx into src/shared/ui/Select.tsx as a button-triggered listbox: the trigger reuses the shared CONTROL class (extracted to src/shared/ui/control.ts, previously duplicated in Field.tsx and Combobox.tsx) plus a chevron, and the popup is OptionList/OptionItem/OptionNotice from src/shared/ui/options.tsx, extracted from Combobox so both controls render one styled list.

The API changed from option children to `options: readonly Option[]` and `onChange(value: string)` (the combobox's shape); Option replaces ComboboxOption. Every call site migrated, and FormSelectField takes options too. A placeholder (default "Selecione") covers the unset value, so the old empty-value option rows became either a real entry in the array (filters like "Todos os profissionais") or were dropped; SheetFieldControl keeps an explicit empty entry only when the field is optional, so an answered optional field stays clearable.

Trade-off accepted: the native mobile picker and native form submission are gone (a hidden input carries name), in exchange for one visual language across select and combobox. Keyboard support is implemented on the trigger (arrows, Enter/Space, Escape) with aria-activedescendant.
